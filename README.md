# RHS Computing — C# Starter

**Start here:** Open `Program.cs`, then press **F5** to run it.

This is a ready-configured C# console workspace for GCSE and A Level Computer Science. You can add more `.cs` files for classes, inheritance and polymorphism without changing the setup.

## Student instructions

1. Open `Program.cs`. It should be open automatically.
2. Press **F5** (or choose **Run → Start Debugging**). If asked, select **Run C# Program**.
3. Watch the **Terminal** panel at the bottom. Type your name and press **Enter**.
4. Edit `Program.cs` and press **F5** again to test your changes.
5. Before finishing, save your work in your own **private GitHub repository** as described below.

**If F5 does not work:** Open **Terminal → New Terminal**, type `dotnet run` and press Enter.

### First five-minute challenge

- Change the welcome message to your own text.
- Ask the user for their favourite game.
- Display a sentence containing their name and favourite game.

### Save work permanently

If you opened this project with **Use this template → Open in a codespace**, the codespace is initially an unpublished copy. Do not rely on it as your only copy of coursework.

1. Click **Source Control** (branch icon on the left).
2. Enter a short commit message, such as `My first C# program`, and select **Commit**. Accept the prompt to stage changes if shown.
3. Select **Publish Branch** and choose a **private GitHub repository**.
4. Next lesson, open that private repository and reopen its Codespace from **Code → Codespaces**. You can also see existing Codespaces at https://github.com/codespaces.

**Keep your GitHub username and repository link somewhere safe.** Your teacher may ask you to give them access to your private repository to review your work.

## Teacher setup (one time)

1. Create a new, separate GitHub repository, e.g. `RHS-CSharp-Starter`. Do not place this starter into the live `reepham-computing` website repository.
2. Add all files from this starter archive, preserving the hidden `.devcontainer` and `.vscode` directories. Commit the files.
3. Open **Settings → General** and check **Template repository**.
4. Test it yourself with **Use this template → Open in a codespace**. Wait for the environment to finish setting up, then open `Program.cs` and press **F5**.
5. Give students the link to the template repository. Demonstrate opening and saving once before independent work.

### Recommended first lesson

Show `Program.cs` on the board. Students open their own workspace, press F5, change two lines and publish their own private repositories. Once that works for the whole class, introduce multiple files and OOP tasks.

### Important classroom notes

- **Each student gets an independent Codespace.** This is a shared configuration, not a shared editing session.
- **Codespaces are metered.** Check who pays before creating a Codespace, use a small (2-core) machine where available, and stop it after the lesson. Check personal and organisation usage limits.
- **Do not use GitHub Classroom.** The service closed on 28 August 2026; use repository templates instead.
- **For paired programming:** VS Code Live Share supports collaborative editing within a Codespace, but that is optional.
- **If the school blocks GitHub Codespaces:** `Program.cs` can be used in a local installation of Visual Studio Code with .NET 10 installed, but that requires local setup.
